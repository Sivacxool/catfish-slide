# CATFISH — Ocean Precision

เว็บพรีเซนต์เครื่องฟักไข่ปลาดุกอัจฉริยะของทีม Wongnaieiei จำนวน 16 สไลด์ อ้างอิง Pitching.pdf และใช้ภาพที่สกัดจากเอกสาร

## เปิดใช้งาน

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

เปิด URL ที่แสดงในเทอร์มินัล ต้องใช้ Node.js 22.13 ขึ้นไป ฟอนต์และภาพเก็บไว้ในโปรเจกต์เอง ไม่มีการเรียกฟอนต์ภายนอกระหว่างพรีเซนต์

## วิธีพรีเซนต์

- ปุ่มลูกศรด้านล่าง หรือ ← / → / Space / PageUp / PageDown เพื่อเปลี่ยนหน้า
- Home / End เพื่อไปหน้าแรกหรือหน้าสุดท้าย
- F หรือปุ่มพรีเซนต์เพื่อเปิด/ปิดเต็มจอ
- M หรือปุ่มคลื่นด้านบนเพื่อหยุด/เปิดภาพเคลื่อนไหว
- ปุ่มสี่ช่องเปิดสารบัญ ปุ่มบันทึกเปิดคำแนะนำสำหรับผู้บรรยาย กด Esc เพื่อปิดหน้าต่าง
- โหมดอ่านแสดงเนื้อหาทุกหน้าและเป็นค่าเริ่มต้นบนหน้าจอไม่เกิน 760 px
- โหมดสไลด์เปิด autoplay ได้ หน้าละ 16 วินาที หยุดเมื่อจบ และหยุดเมื่อผู้ใช้เปลี่ยนหน้าเอง
- แหล่งข้อมูลของแต่ละหน้าเปิดดูภาพหน้า PDF ที่เกี่ยวข้องได้
- รองรับลิงก์เจาะจงหน้า เช่น `#slide-8`

## ขอบเขตข้อมูล

นี่คือเว็บไซต์พรีเซนต์ ไม่ได้เชื่อมเครื่องฟัก เซนเซอร์ หรือโมเดล AI จริง เครื่องคำนวณอัตราฟักใช้ค่าที่ผู้ใช้กรอกและระบุข้อมูลจำลองอย่างชัดเจน ภาพเครื่องเป็นแบบจำลองจากเอกสาร ผลที่คาดหวังไม่ใช่ผลการทดลองยืนยันแล้ว

กราฟอุณหภูมิใช้อัตราฟักจาก Rey et al. (2025): 43.4% ที่ 29°C และ 26.6% ที่ 32°C พร้อมลิงก์บทความ ในเอกสารต้นฉบับหน้า 16 ใช้ตัวเลขต่างจากบทความ ข้อมูลผลผลิตปทุมธานีระบุว่าเป็นข้อมูลตาม PDF ที่ยังไม่ได้ยืนยันตารางต้นทาง

## แก้เนื้อหาและดีไซน์

- `app/deck-data.ts`: หัวข้อ หมวด แหล่งข้อมูล และบันทึกผู้บรรยาย
- `app/page.tsx`: องค์ประกอบทั้ง 16 หน้าและระบบควบคุม
- `app/globals.css`: โทน Ocean Precision การจัดวาง และ responsive styles
- `public/assets/manifest.json`: ชื่อภาพ หน้า PDF และรหัสภาพต้นทาง
- `public/sources/`: ภาพหน้า PDF สำหรับแหล่งอ้างอิง
- `public/fonts/`: ฟอนต์ Noto Sans Thai และ Manrope ที่ใช้ในเว็บ

ภาพและตราสถาบันมาจากเอกสารที่ผู้ใช้ให้ไว้ การเผยแพร่ต่อควรคงบริบทและเครดิตตามเอกสาร

## ตรวจงาน

```sh
npm run lint
npm run build
npm run test:browser
```

การทดสอบเบราว์เซอร์ต้องมีเซิร์ฟเวอร์ทำงานอยู่ ค่าเริ่มต้นคือ `http://localhost:4173` และ Chrome ในตำแหน่งติดตั้งมาตรฐานบน Windows เปลี่ยนได้ด้วย `TEST_URL` และ `CHROME_PATH` ผลอยู่ใน `outputs/qa/` ทดสอบ 6 ขนาดจอ 16 สไลด์ การนำทาง เครื่องคำนวณ หน้าต่างข้อมูล การเข้าถึงตามกฎ axe และการควบคุมพรีเซนต์

สร้าง production ด้วย `npm run build` และตรวจ production ด้วย `npm run start -- --port 4180` ผลตรวจและข้อจำกัดอยู่ใน `design-qa.md` การผ่านการตรวจเหล่านี้ไม่ได้รับประกันว่าปราศจากบัคในทุกอุปกรณ์หรือทุกเบราว์เซอร์
